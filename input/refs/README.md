# References

These works are by others and are not in this repository; only their checksums are (`SHA256SUMS`). Get them from their
publishers and place them here under the names below if you want to verify the checksums. Nothing in the build needs them.

| Local name | Work |
|---|---|
| `hsu-array2015-accelerating-information-experts.pdf` | Aaron W. Hsu, *Accelerating Information Experts through Compiler Design*, ARRAY 2015. doi:10.1145/2774959.2774968 |
| `hsu-2019-data-parallel-compiler-hosted-on-gpu.pdf` | Aaron W. Hsu, *A Data Parallel Compiler Hosted on the GPU*, 2019 |
| `goodrich-kloss-tiered-vectors-author-version.pdf` | Michael T. Goodrich, John G. Kloss II, *Tiered Vectors* (author's version) |
| `eml/2603.21852v2.pdf` | Andrzej Odrzywołek, *All elementary functions from a single operator*, arXiv:2603.21852v2 |

The video that led to the last one: a3kino, *Can You Build a Scientific Calculator with ONE Button?*,
https://www.youtube.com/watch?v=aEY_hh2BiJ0 . A local transcript is kept in `eml/`, also outside git.

`input/models/` works the same way: the Q8_0 GGUF models are not in this repository, only `SHA256SUMS`.
